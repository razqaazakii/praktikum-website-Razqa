# Dashboard Pemantauan Mesin Industri

Aplikasi web untuk monitoring performa mesin industri secara langsung.

## Teknologi
- Next.js
- Tailwind CSS
- Node.js

## Cara Menjalankan
1. Unduh repositori ke komputer lokal dengan perintah 'git clone https://github.com/xxxxx/xxxx.git.
2. Masuk ke folder proyek dnegan perintah 'cd xxxx'
3. Installl dengan perintah 'npm install'\
4. Jalankan server dengan perintah 'npm run dev'
5. Buka `http://localhost:3000`untuk melihat aplikasi
